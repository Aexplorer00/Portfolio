# Laxmi Prasad Dooda — SRE / DevOps portfolio

A custom, responsive engineering portfolio centered on infrastructure, delivery automation, Kubernetes, observability and reliability.

## Stack
Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS and Lucide icons. Configured for static export and GitHub Pages at `/Portfolio/`.

## Sections
- Engineering-led introduction and terminal-style profile
- About and professional focus
- Five switchable case studies with technical problem, approach and outcome
- Practical skill categories instead of arbitrary percentage scores
- Professional background and engineering principles
- Contact via email, GitHub and LinkedIn

## Local development
```bash
npm ci
npm run dev
npm run build
```
